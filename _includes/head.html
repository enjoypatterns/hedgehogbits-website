{%- comment -%} GitHub Pages can't send security headers, so the policy is set here instead. The site loads nothing from other origins and, by default, runs no JavaScript. The JSON-LD blocks are data, not scripts, so default-src 'none' doesn't affect them. connect-src 'self' only lets audit tools such as Lighthouse fetch robots.txt. frame-ancestors can't be set in a meta tag; that needs a real header. Pages that need JavaScript (the free tools) opt in through front matter: scripts: same-origin script files.
